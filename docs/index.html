КУРАТОРСКОЕ ВЫСКАЗЫВАНИЕ

У привычек тоже
есть посмертие.

Уведомления, непрочитанные сообщения, облачные воспоминания и отменённые маршруты. Мы представили их музейными находками: у каждой появились вес, поверхность и тень.

Замысел рождается в споре двух языковых агентов. Третий смотрит на настоящую картину и предлагает изменения. Здесь можно увидеть весь процесс — включая версии, которые не стали финальными.

МЕТОД

Картина —
это разговор.

  1. 01

    Куратор задаёт смысл

    Предлагает метафору. Художник переводит её в композицию, а куратор оспаривает слабое место.

  2. 02

    Художник собирает образ

    Фиксирует материал, свет и отношения объектов. Image Generation API создаёт первую версию.

  3. 03

    Критик действительно смотрит

    VLM получает изображение, описывает видимые детали и предлагает конкретные изменения. Художник создаёт вторую версию.

  4. 04

    Сохраняется лучший вариант

    Четыре критерия по 1–5 баллов. Выбирается максимальная сумма; при равенстве — ранняя версия. Все исходники остаются открыты.

Оценки критика субъективны. Новая версия может оказаться слабее первой. Промпты, изображения и ответы API сохраняются без ручной подмены.
