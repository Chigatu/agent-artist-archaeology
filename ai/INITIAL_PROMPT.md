# Исходное задание кодинг-агенту

Подготовить лабораторную №1 «АХ: Агент-художник» по заданию
https://github.com/MAILabs-Education/Agent_Artist с опорой на материалы
https://github.com/yandex-ai-studio/ai-studio-course.

Команда: Аршинов Иван, Барулева Кристина, Губенков Илья, Якушина Анна.

Нужно реализовать многоагентное создание 3–5 концептуальных картин,
сохранить диалоги, оформить Jupyter Notebook и отчёт по шаблону.
Дополнительные цели из критериев: визуальная обратная связь, галерея
для GitHub Pages, открытая модель с Hugging Face.

Доступ к AI Studio предоставлен преподавателем через отдельный `.env`.
Адрес и значения ключей в публичных артефактах намеренно не приводятся.

ИИ помогает писать код, разрабатывать концепцию и оформлять результаты.
Сведения о личном вкладе участников нельзя придумывать.
