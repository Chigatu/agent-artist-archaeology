# Археология будущего — следы присутствия

Лабораторная №1 «АХ: Агент-художник» по Yandex AI Studio.

**Команда:** Аршинов Иван, Барулева Кристина, Губенков Илья, Якунина Анна.

[Репозиторий на GitHub](https://github.com/Chigatu/agent-artist-archaeology)

Воображаемый музей 2126 года хранит материальные следы цифровых привычек.
Четыре картины возникают в диалоге куратора и художника; VLM рассматривает
настоящие изображения и запускает доработку. Сохраняются обе версии,
а финал выбирается по заранее заданной рубрике. Для первого экспоната
дополнительно запускается открытая SD-Turbo с Hugging Face.

## Просмотр без ключей и генерации

Откройте ноутбук на GitHub: изображения и результаты уже встроены в outputs ячеек.
Для интерактивной галереи из корня репозитория:

```bash
python3 -m http.server 8080 --directory docs --bind 127.0.0.1
```

Затем откройте `http://127.0.0.1:8080/`. Сайт не вызывает LLM, не требует ключей
и ничего не отправляет в AI Studio: он читает сохранённый `gallery.json`.

## Повторный запуск

Нужен Python 3.10+ (эксперимент выполнен на Python 3.12).

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.sample .env
# Заполните folder_id и api_key, полученные от преподавателя.
python agent_artist.py
```

API-запросы используют учебную квоту. `.env` игнорируется системой контроля версий.
Адрес раздачи ключей и сами ключи в публичной работе отсутствуют.

Запуск переиспользует уже сохранённые этапы и изображения. Чтобы провести
**новый независимый эксперимент**, скопируйте проект в отдельный каталог,
сохраните архив прежних результатов и укажите пустые `DATA` и `ASSETS`
в ноутбуке до вызова `make_painting` (либо переместите прежние `data/*.json`
и изображения из копии). Два процесса не должны писать одну картину одновременно.

```bash
# Только одна картина; две версии — значение по умолчанию.
python agent_artist.py --only 01-notification
# Пересобрать сайт и Markdown-журнал без запросов API.
python agent_artist.py --export-only
# Открытый рендерер (скачивание весов около 2 ГБ, Apple MPS/CUDA/CPU):
python -m pip install -r requirements-openweight.txt
python agent_artist.py --only 01-notification --openweight
```

Локальная SD-Turbo: **Powered by Stability AI**. Условия и атрибуция —
в [MODEL_CARD.md](MODEL_CARD.md), [NOTICE](NOTICE) и [лицензии](licenses/STABILITY_AI_LICENSE.md).

## Схема

```text
Тема → Куратор (замысел) ↔ Художник (композиция)
                     ↓ возражение куратора
              Художник → Image API → версия 1
                                        ↓ изображение
                                  VLM-критик
                                        ↓ замечания
              Художник → Image API → версия 2
                                        ↓ изображение
                                  VLM-критик
                                        ↓
             max суммы оценок → финал + все альтернативы
                                        ↓
                           JSON → Notebook / галерея
```

## Проверка артефактов

```bash
python scripts/build_notebook.py
python scripts/execute_notebook.py
python scripts/validate.py
```

Ноутбук по умолчанию выполняется в режиме просмотра сохранённых результатов;
`RUN_GENERATION = False`. Полный код находится и в ноутбуке, и в `agent_artist.py`.
Скрипт сборки синхронизирует их. Проверка сверяет реальные файлы и хеши,
полноту диалогов, входные изображения VLM, правило выбора и выполнение ячеек.
`requirements-lock.txt` фиксирует окружение проведённого запуска.

Галерея также проверена в браузере: все четыре экспоната и SD-Turbo загрузились,
переключение версий и полноразмерный просмотр работают, на ширине 751 px
горизонтального переполнения нет.

## GitHub Pages

Workflow `.github/workflows/pages.yml` публикует каталог `docs/` при push в `main`.
В Settings → Pages → Build and deployment нужно выбрать **GitHub Actions**.
Оригинальные изображения, версии и диалоги доступны в самой галерее.
